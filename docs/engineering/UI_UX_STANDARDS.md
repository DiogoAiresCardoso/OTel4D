# UI and component usability

Apply these rules to a visual demo, settings dialog or other UI introduced by a change. The runtime library uses an OTLP adapter to encode messages and uses the protocol contract for validation.

Reuse the host's design system, components and tokens. Preserve keyboard navigation, shortcuts, focus order, contrast and accessible names. Cover loading, empty, success, failure and offline states. Communicate the result of an action and make destructive choices explicit. Verify resizing and localization where the interface supports them. Target WCAG 2.2 AA for web interfaces and test with keyboard and assistive technology where applicable.

For design-time Delphi components, keep defaults predictable, avoid network activity in the IDE and make runtime activation observable.
